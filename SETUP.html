⏱ Tasky Setup Guide

Connect your extension so every task goes straight to your Google Sheet

🗺 How it works

Each person has their own Google Sheet. The Tasky extension sends your task data directly to it — no middleman, no shared server needed for your personal data.

Tasky Extension
→
Your Google Apps Script
→
Your Google Sheet
Tasky Extension
→
Team Dashboard Server
→
Live Team Dashboard
The extension can send to both at the same time. Your Sheet gets your personal history; the dashboard shows the whole team live.

📋 Step 1 — Create your Google Sheet

This is the spreadsheet where all your tasks will be stored.

1
Go to Google Sheets Visit sheets.google.com and click + Blank to create a new spreadsheet.
2
Name your spreadsheet Click "Untitled spreadsheet" at the top and rename it to something like Tasky – My Tasks.

⚙️ Step 2 — Add the Apps Script

This script receives data from your extension and writes it to the sheet.

1
Open Apps Script In your spreadsheet, click Extensions → Apps Script. A new tab opens with a code editor.
2
Replace all the code Select everything in the editor (Ctrl+A / Cmd+A), delete it, then paste the entire contents of google-apps-script.js (included in this zip).
3
Save the project Press Ctrl+S (or Cmd+S on Mac). You can name the project anything, e.g. "Tasky".

🚀 Step 3 — Deploy as a Web App

This gives the script a URL that your extension can call.

1
Click Deploy → New deployment Top-right of the Apps Script editor.
2
Configure the deployment • Select type: Web App
• Execute as: Me (your Google account)
• Who has access: Anyone
3
Click Deploy and authorise Google will ask you to authorise the script. Click Authorise access → Advanced → Go to [project name] → Allow.
4
Copy your Web App URL You'll see a URL like:
https://script.google.com/macros/s/XXXXXXXXXXXXXXXXX/exec
⚠️ Keep this URL private — anyone with it can send data to your sheet.

🔌 Step 4 — Connect the extension

Tell the Tasky extension to send your data to your Google Sheet.

1
Open Tasky extension settings Click the Tasky icon in Chrome → open Settings or the ⚙️ icon.
2
Find the API / Endpoint field Look for a field labelled Google Sheets URL, Web App URL, or API Endpoint.
3
Paste your Web App URL and save Paste the URL from Step 3 → click Save or Connect.
4
Test it Complete or park a task. Within a minute you should see a new row appear in your Google Sheet under a tab named after your email username.

📊 What you get in your sheet

Three auto-managed tabs are created for you:

1
Your name tab (e.g. "john") Every task you complete, park, or block — one row per task with full details: task name, job, stage, status, start/end time, duration, and a link back to the task.
2
📊 Summary Daily totals — completed, parked, blocked, total time, average per task. Auto-refreshes every time new tasks come in.
3
⚡ Active Shows your current status: what task you're working on right now and how many tasks are parked. Updated by the heartbeat every minute.

❓ FAQ

Do I need to set this up again if the script is updated?
Yes — if you receive a new version of google-apps-script.js, go back to Extensions → Apps Script, replace the code, then click Deploy → Manage deployments → Edit (pencil) → Version: New version → Deploy. Do NOT create a new deployment — update the existing one so the URL stays the same.
Can I also use the team dashboard at the same time?
Yes. The extension can send to multiple URLs. Add your Google Apps Script URL for your personal sheet AND the team server URL for the live dashboard. Both receive the same data simultaneously.
Is my data private?
Your Google Sheet is private to your Google account. Only you can see it unless you share it. The "Anyone" access on the Web App only means the extension can post data to it — it does NOT give anyone read access to the sheet itself.
Why do I need "Execute as: Me"?
This means the script runs with your Google account's permissions, so it can write to your sheet. If you set it to "Execute as: User accessing the web app", the extension (which has no Google login) would have no permission to write anything.
Tasks aren't appearing in my sheet — what do I check?
1. Open your Web App URL directly in a browser — you should see {"ok":true,"message":"Tasky Sheet v9 is live!"}
2. Check the extension settings — make sure the URL ends in /exec, not /dev
3. In Apps Script → Executions — you can see every call and any errors
4. Make sure you authorised the script (Step 3 → authorise access)
How do I update the script without losing my data?
Your data is in the spreadsheet rows — the script never deletes rows. You can update the script code any time without affecting existing data. Just replace the code and redeploy as a new version of the same deployment.
